# 🚀 NovaPulse AI Studio | استوديو إنتاج ونشر الفيديوهات بالذكاء الاصطناعي

منصة متكاملة باللغة العربية متخصصة في التخطيط والإنتاج التلقائي للفيديوهات القصيرة العمودية (9:16 Facebook Reels) ونشرها على فيسبوك بنظام متعدد المستخدمين حقيقي ومعزول أمنياً.

---

## 🌟 مميزات المنصة

- **نظام متعدد المستخدمين (Multi-User Engine)**:
  - تسجيل، دخول، وخروج مع عزل كامل للبيانات (User Data Isolation).
  - تشفير كلمات المرور باستخدام Salt وPBKDF2.
  - لوحة تحكم وإحصائيات مستقلة تماماً لكل مستخدم.
- **تكامل Facebook Meta Graph API الرسمي**:
  - استقلالية تامة: كل مستخدم يربط صفحته الخاصة دون الاعتماد على صفحة صاحب المنصة.
  - طريقتان للربط: جلب الصفحات برمز المستخدم (OAuth / `/me/accounts`) أو الربط المباشر برمز الصفحة.
  - فحص مباشر لحالة الرمز (`متصل`، `منتهي الصلاحية`، `يحتاج إعادة ربط`).
  - نشر الفيديوهات والريلز مباشرة على الصفحة.
- **محرك الذكاء الاصطناعي (Nova AI & OpenRouter)**:
  - محرك أساسي: OpenRouter (`openrouter/free`).
  - دعم العربية، الدارجة المغربية، والإنجليزية.
  - كتابة السيناريوهات وتقسيم المشاهد بالثواني (60-90 ثانية).
  - اقتراح الأفكار الفيروسية والخطافات الخاطفة (Viral Hooks).
  - محرك احتياطي ذكي لضمان استمرارية التشغيل 100% بميزانية 0$.
- **استوديو إنتاج الفيديوهات (Canvas 2D + Web Audio API)**:
  - 6 مؤثرات بصرية حركية (نيون 3D، شبكة ذكاء اصطناعي، أمواج لونية، جزيئات مجرة، طاقة نابضة، شظايا سينمائية).
  - نصوص حركية سينمائية كبيرة ملائمة لشاشات الهواتف.
  - ترجمة توضيحية متزامنة (Subtitles).
  - توليد وإدراج موسيقى تصويرية مرخصة مجاناً.
  - تصدير فيديو حقيقي 1080p بمقاس 9:16 بصيغة `.webm` و `.mp4`.
- **نظام الإنتاج التلقائي والجدولة**:
  - هدف يومي (1 إلى 5 فيديوهات / يوم).
  - أوقات نشر مخصصة (مثل 14:00 و20:00).
  - قائمة انتظار ذكية مع إعادة المحاولة في حال فشل النشر.
- **إدارة السلاسل (Series)**:
  - الحفاظ على تسلسل القصة والشغف بين الحلقات.
  - توليد الحلقة القادمة بنقرة واحدة.

## 🚀 التثبيت والتشغيل السريع (Quick Start)

### 1. استنساخ المشروع وتثبيت الاعتماديات:
```bash
# تثبيت الحزم
npm install
```

### 2. إعداد المتغيرات البيئية:
انسخ ملف `.env.example` إلى `.env`:
```bash
cp .env.example .env
```
افتح ملف `.env` وقم بملء البيانات الخاصة بك (مفتاح OpenRouter، ومعرف تطبيق فيسبوك، ورابط الموقع).

### 3. بناء وتصيير ملفات الواجهة (Production Build):
```bash
npm run build
```

### 4. تشغيل الخادم:
```bash
# وضع التطوير:
npm run dev

# أو وضع الإنتاج الفعلي:
npm start
```
سيعمل التطبيق مباشرة على: `http://localhost:3000`.

## ⚙️ إعدادات الربط الخارجي

### 1. إعداد OpenRouter (الذكاء الاصطناعي):
1. سجل في [openrouter.ai](https://openrouter.ai).
2. أنشئ مفتاح API جديد.
3. ضعه في متغير `NOVA_AI_API_KEY` في ملف `.env` (أو يمكن لكل مستخدم إدخال مفتاحه الخاص من صفحة الإعدادات داخل المنصة).

### 2. إعداد تطبيق Meta Facebook:
1. توجه إلى [developers.facebook.com](https://developers.facebook.com).
2. أنشئ تطبيقاً جديداً بنوع **Business** أو **Other**.
3. أضف منتج **Facebook Login for Business**.
4. اضبط الصلاحيات التالية:
   - `pages_show_list`
   - `pages_read_engagement`
   - `pages_manage_posts`
   - `publish_video`
5. انسخ **App ID** و **App Secret** إلى ملف `.env`.
6. أضف رابط الموقع في قائمة **Valid OAuth Redirect URIs**:
   `https://yourdomain.com/facebook-callback`

## 🔒 الأمان وعزل البيانات (Security)

- لا يتم تضمين أي مفاتيح سرية في كود الواجهة الأمامية.
- كافة طلبات الـ API محمية عبر `Bearer JWT/Session Tokens`.
- رموز وصول صفحات فيسبوك تُحفظ في الخادم فقط مشفرة ولا تظهر للمستخدمين أبداً.
- كل مستخدم يستطيع الوصول فقط إلى الفيديوهات والسلاسل والصفحات التي أنشأها بحسابه.
